# 示例情景与资料来源

数据使用固定历史背景：**2025 年 9 月 18 日 10:30 UTC+8**，当前简报截止于 09:30。共包含 25 条来源记录、两个事件、两个专题、三期简报、六项资产、九条收藏、六条浏览记录和五个会话。

文案为原创整理。公共文件提供部分事实，虚构报道构成连贯的交互情景。价格、涨跌幅、收益率观察、图表走势、加密资产资金费率和网络活动数值均为示意数据，不是历史行情记录。全局 DEMO 标识适用于整个体验。

## 连贯体验路径

1. **简报 → 依据 → 原始发布 → 其他发布 → 更正。** 09.18 简报合并松岭园区的两份报道。产业观察在 08:45 报道总容量 48 MW、首期 24 MW；08:58 的另一份跟进介绍电网审核。09:05 的转载正文相同，但保留自己的来源和时间。10:05 原来源将设备交付月份从九月更正为十二月，10:06 接收。这是报道错误，不是项目刚宣布延期。园区、容量与项目报道均为虚构，不暗示真实芯片供应商。
2. **事件 → 固定版本依据 → 更新后的专题。** 园区事件在 09:12、10:10 发布版本，供电专题在 09:25、10:20 发布版本，各自保留截止时间与材料版本。旧整理确实写了错误月份，因此显示说明；简报重点没有重复该月份，无需继承更正警告。
3. **黄金 → 普通更新 → 保存早期记录。** 08:10 观察为每盎司 3,658.20 美元、上涨 0.23%；10:15 跟进为 3,672.40 美元、上涨 0.62%，与 10:30 行情快照一致。这属于新信息。阅读与收藏早期记录展示未读更新和历史版本固定的差异。
4. **资产 → 明确相关内容 → 上下文对话。** NVDA 对应收入图表，MSFT 对应资本开支和署名观点，AAPL 对应上市与财报，BTC 对应资金费率，ETH 对应事件及二层背景，XAU 对应价格观察及 ETF 背景。园区、泛芯片封装解释与广义宏观报道不因同主题就绑定股票。
5. **图片、视频、音频与长文。** 英伟达内容提供可放大的收入图表和交付示意图。园区独立视频与供电专题保留可播放的 18 秒动画及双语字幕。能源署解释提供图示和视频，林序观点提供合成音频。媒体均为原创说明，不是真实现场或作者录音。SVG 收入图表使用英文标签，配有本地化说明和替代文本。
6. **偏好与个人记录。** 来源关注、主题兴趣、排除、自选和概览配置相互独立。预置对话覆盖原始报道、已保存专题版本、简报和资产。收藏包含图片、视频、普通更新和旧版整理，主题重叠展示跨领域内容，不增加资产标签。
7. **直接兴趣以外的推荐理由。** 北岸电网是虚构公用事业主体：两座新变电站延期六周，已有服务不受影响。该能源报道设为最高编辑优先级，默认显示“重要信息”。仅标记“国债与利率”的原创债券回报解释显示“拓展视野”。两者均为合格候选，不暗示自选资产关系或外部报道地址，偏好变化后按实际关系显示。最多将一条重要信息放到前三位、一条拓展内容放到前六位，不绕过筛选。

## 示例维护

- `src/demo-scenario.ts` 管理时钟、当前简报标识和记录命名空间。
- `src/data.ts`、`src/collections.ts`、`src/briefs.ts` 管理来源正文、依据快照和预写整理；`src/longform.ts`、`src/media.ts` 保存共享长文与媒体定义。平台文案提供英文翻译，个人会话消息保留原文。
- `sift-sep2025-v2-*` 保存本批数据的收藏、历史、会话和简报。旧记录继续留在原键下，不覆盖；来源关注、兴趣、自选、概览、语言与外观沿用各自键。重置与清空处理当前情景记录，具体边界见[演示说明](demo.md)。
- 新内容需要唯一标识、有效来源、支持的主题和明确资产引用。修订保留来源，转载保留自身发布时间。接收时间不得晚于引用它的整理或简报截止时间，不把假设中的未来更新补入早期快照。
- 测试检查引用、时间顺序、重复发布、更正、行情单位、双语覆盖、本地媒体及预置上下文。修改示例后运行 `npm test` 和 `npm run build`。
