# 演示说明

[在线演示](https://sift-demo.liuqiang1357.chatgpt.site)使用固定内容、示意行情和模板回复，数据保存在当前浏览器。本地修改需要另行部署；当前尚未接入真实资讯或 AI 服务。

[产品设计](product-design.md)描述目标体验，[内容规则](content-rules.md)定义信息处理规则，本文说明仓库中实际运行的能力。资料出处与完整阅读路径见[示例情景与资料来源](demo-scenarios.md)。

## 已实现能力

| 范围 | 已实现行为 | 限制 |
| --- | --- | --- |
| 首次使用与偏好 | 主题兴趣、自选、来源关注、偏好描述、多推荐／少推荐／排除 | 文本解释使用中英文别名与规则，未接入语言模型。 |
| 简报 | 从预写重点中选择，保存文案与引用，查看历史、依据、收藏、阅读理由和追问 | 没有定时发布或自动生成下一期。 |
| 探索与搜索 | 关注、推荐、热点、专题，主题筛选，内容／来源／资产搜索 | 内容目录、重要性和关联关系预先设定。 |
| 阅读 | 报道、事件、专题、历史版本、其他发布、相关资产、延伸阅读及折叠区域 | 没有外部采集、语义聚类或自动核实。 |
| 媒体 | 图片放大、本地音视频、双语字幕、文字说明和部分缩略图 | 使用原创说明媒体，不是真实现场视频或作者录音。 |
| 行情 | 可配置的紧凑概览、自选、行情详情、图表区间和明确关联内容 | 价格与走势是示意数据，没有实时行情、交易或异常检测。 |
| 对话 | 内容版本、简报或资产上下文，独立会话、保存回复与返回入口 | 使用本地模板，没有模型、工具执行或推断记忆。 |
| 个人记录 | 收藏、历史、对话、管理、重置与清空 | 仅保存在浏览器，没有登录和跨设备同步。 |

支持中英文及浅色、深色、跟随系统外观。个人输入和已保存对话保留原文。宽屏展示场景导航与手机预览，宽度不超过 760 px 时直接显示应用。

探索与行情支持标签滑动，桌面预览也支持鼠标拖动。简报、探索、行情支持下拉刷新，展示加载与暂无新数据反馈，不改变行情或重新计算简报。统一的 DEMO 标识说明演示属性，阅读页不重复提示。

## 建议验证路径

- **合成简报与依据**：打开 09.18 简报，展开松岭园区重点。两份报道合成一个重点，各自版本保留；其中一份材料后续更正，不重写该重点。
- **重复发布与修订**：搜索园区报道，查看“其他发布”，再比较原来源的更正版。转载保留自己的旧文与发布时间。
- **兴趣之外的理由**：默认选择下，虚构的北岸电网报道显示“重要信息”，债券回报解释显示“拓展视野”。已有偏好可能改变这些标签。
- **媒体与上下文**：打开英伟达收入图表或 18 秒园区视频，围绕内容提问。星光入口携带具体版本，会话内加号用相同初始上下文创建独立对话。
- **记录与恢复**：在收藏页取消一篇内容或整期简报，再原地收藏。来源关注与自选也保留本次访问中的取消行，再次进入时才移除。

## 数据与筛选边界

时钟固定为 **2025-09-18 10:30 UTC+8**，当前简报截止时间为 **09:30**。显示跟随设备时区，不跟随界面语言。探索使用 24 小时信息窗口，搜索与已保存版本不受该窗口限制。

数据包含 25 条来源记录、两个事件、两个专题、三期简报、六项资产、九条初始收藏、六条浏览记录和五个会话。公共文件提供部分历史事实，虚构报道与数值观察补齐交互情景。真实支撑文件使用“查看参考原文”，虚构报道不编造外链。

当前 `SourceItem` 对应发布记录，`duplicateOf` 和 `supersedes` 分别连接重复发布与修订，列表据此生成阅读视图。来源内容无需另建实体，简报沿用独立结构；统一概念不要求重构存储。

普通列表统一保留类型、更新状态、来源和时间，默认省略主题标签；详情、主题筛选和阅读理由继续使用主题。

导入示例时检测重复正文：完整文本至少 120 个字符，只归一化空白，跳过封面或媒体内容、片段及生成摘要。已有重复关系与核对后的不匹配记录优先。尚未实现近似正文的语义匹配。

来源与整理关系、资产关系、重要错误说明和编辑优先级均为预设。测试覆盖接收到新材料、尚未完成整理的中间阶段；界面固定时钟位于全部示例更新之后。因此能够验证规则，不能证明实时编辑服务能力。

阅读理由按当前选择及展示引用计算，依次优先自选资产、主题兴趣、关注来源。没有直接匹配时，优先级 3 显示“重要信息”，其他合格内容显示“拓展视野”。命中少推荐或排除的内容不显示正向理由。只有推荐和简报显示理由，推荐菜单复用同一结果。

在已合格的推荐中，最多将一条“重要信息”提前到前三位，一条“拓展视野”提前到前六位，以便看到示例，不补入已被筛掉的内容。这是演示参数，不是已验证的探索比例；缺少合适候选时也不保证出现。

当前简报最多选取三个预写重点，排除不可用或被排除的依据，保存结果快照。当前阅读理由可以随选择变化，不属于固定正文。布局和图标调整也适用于已保存内容，但不改变其文案与引用。

## 本地数据与设置

新浏览器默认关注林序、产业观察，自选 NVDA、BTC、XAU，兴趣为宏观经济、AI 与科技，少推荐加密资产。已有选择会保留。示例偏好描述可编辑，不会每次访问都重新应用。

内容记录使用 `sift-sep2025-v2-*` 命名空间，旧情景记录仍保存在旧键中。选择、概览、语言和外观继续使用各自已有键。支持的旧偏好会迁移，不凭空新增兴趣或重写收藏。线上与本地属于不同站点，浏览器存储互不共享。

设置提供两项演示操作，执行前均需确认：

- **重置示例数据**：用完整默认示例替换选择与记录，恢复默认概览。
- **清空用户数据**：清空当前情景的个人记录与选择，移除旧关注／偏好键，并创建无个性化的简报和默认概览。刷新不会重新填入已清空的个人记录。旧情景的记录命名空间仍保留，因此不等于删除所有历史数据集。

两项操作都保留语言和外观，不提供撤销。普通历史／对话删除有独立的页面内撤销，删除单条记录不重置其他选择。

## 开发与验证

使用 Node.js 22.12 或更高版本。应用采用 React 19、TypeScript 7、Vite 8 和 Lucide 图标。

```sh
npm ci
npm run dev
npm test
npm run build
```

开发服务每 300 毫秒轮询文件，避免原生文件事件遗漏导致修改不刷新。`npm run preview` 预览构建产物，`npm run format` 格式化应用代码和配置。

行为测试覆盖身份、引用、截止时间、重复发布、排除、相关性、简报快照、手势、翻译、行情与示例。修改界面后，还应按影响范围检查窄屏流程、返回导航、折叠状态和明暗外观。测试通过不代表整理质量或推荐效果已获验证。

## 文件职责与部署

- 内容：`src/data.ts`、`src/collections.ts`、`src/briefs.ts` 保存来源、整理版本和预写重点；`src/content.ts` 处理共享筛选与引用规则，`src/duplicates.ts` 处理相同正文关系。
- 偏好与记录：`src/reading-choices.ts`、`src/preferences.ts`、`src/demo-records.ts`、`src/demo-scenario.ts`、`src/store.ts` 分别管理选择、解释、示例、命名空间和存储。
- 展示：`src/App.tsx`、共享组件及 `src/style.css` 构成界面；`src/longform.ts`、`src/media.ts`、`public/media/` 提供长文和媒体；`src/i18n.ts`、`src/translations.json` 管理平台文案。
- 行情与手势：`src/market-overview.ts`、`src/quotes.ts`、`src/gestures.ts`、`src/useFeedGestures.ts` 定义各自规则。

已有 ChatGPT Site 配置位于 `.openai/hosting.json`，静态目录为 `dist/`。获得部署授权后，先验证并构建，复用已配置站点，只发布静态产物。浏览器个人记录和凭据不进入部署产物。
