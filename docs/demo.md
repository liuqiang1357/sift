# Demo 说明

[公开访问](https://sift-demo.liuqiang1357.chatgpt.site)。本 Demo 用于验证功能结构和交互，不连接资讯服务、实时行情或 AI 模型。产品目标见 [功能设计](product-design.md)。

## 当前能力

| 功能 | 已实现 | 演示边界 |
| --- | --- | --- |
| 简报 | 今日要点、往期查看、收藏、详情与追问 | 内容与日期固定，不定时生成；往期内容为复用样本 |
| 探索 | 关注筛选、推荐与热门切换、主题详情、中英文搜索 | 只查本地样本，推荐标记和排序为示例，偏好不参与计算 |
| 行情 | 可编辑市场概览、自选、市场分类、资产详情、周期切换、相关资讯 | 价格和图表固定，周期变化仅作演示 |
| 机构与媒体 | 关注列表、搜索及资讯署名可进入来源详情，查看简介、内容并关注；事件详情署名旁也可直接关注 | 简介与内容均为示例 |
| 作者 | 列表署名、详情关注、作者页及搜索 | 使用虚构作者和固定内容 |
| 个人记录 | 关注、偏好、收藏、浏览和对话历史、历史管理与撤销 | 保存于当前浏览器，无账号与跨设备同步 |
| 对话 | 上下文、示例问题、输入、回复及历史续聊 | 本地模板回答，不检索资料，不执行关注或偏好修改 |
| 设置 | 语言、主题、简报时间、提醒和免打扰 | 通知与时间仅保存设置，不发送通知 |

来源链接指向机构主页，不是情景内容的报道原文；虚构作者观点没有外部原文。页面提供演示标识，不将固定样本描述为真实新闻。

## 展示与交互

宽屏展示场景导航、手机模拟器和设计说明；宽度不超过 760px 时直接显示 App。首次使用流程可从宽屏场景导航进入。

- 市场概览默认展示标普 500、纳斯达克和美元指数。编辑时可从平台列表选择 1–3 项，用上下移动调整顺序，保存后生效；返回放弃修改，恢复默认也需保存。此设置保存在当前浏览器，不影响自选与关注。
- 我的关注只列出已关注对象，资产、主题、作者和机构与媒体均可进入详情。取消项保留至本次列表退出，方便重新关注。
- 收藏的资讯和简报统一按收藏顺序展示，新收藏置顶；可查看详情，返回恢复列表位置。
- 历史页点击“管理”后选择记录，支持全选、确认删除和撤销最近一次删除。删除浏览历史不取消收藏或关注；删除对话包含消息。
- 对话页可开始新对话，保留原对话记录；进入新对话或历史对话时清空未发送的输入。
- 行情图表的横轴随日内、一周和一月切换；进入另一项资产时默认显示日内。
- 内容偏好没有启用开关，自动保存、清空取消。当前不会改变示例推荐。
- 界面与平台示例内容可切换中英文。偏好、对话标题和已有消息保持原文，新回答采用发送时的界面语言。

## 默认记录与本地保存

首次访问默认关注 NVDA、BTC、宏观经济、AI 与科技、虚构作者林序和示例来源产业观察，并提供一条简报收藏、两条资讯收藏、两条浏览记录、两段中文对话及一条中文内容偏好。

每类记录仅在对应本地存储缺失时初始化。已有记录不会被覆盖，清空后的空列表也不会自动补回。设置中的“添加示例收藏和中文对话”会补充缺失的收藏、浏览记录和中文对话，不覆盖已修改的同一条示例。

记录按浏览器和站点地址隔离。本地预览、线上地址及更名前的地址不会共享记录；换设备、换浏览器或清除站点存储后，会重新初始化。语言切换不会创建另一份记录。

## 开发与检查

使用 React 19、TypeScript 7、Vite 8 和 Lucide 图标。需要 Node.js 22.12 或更高版本。

```sh
npm ci
npm run dev
```

默认地址为 [http://127.0.0.1:5173/](http://127.0.0.1:5173/)。

- `npm test`：检查翻译覆盖、双语搜索及示例补充时的数据保留规则。
- `npm run build`：类型检查并输出静态网站到 `dist/`。
- `npm run preview`：本地预览构建产物。
- `npm run format`：格式化应用源码和配置。

涉及交互的修改还需人工检查：详情返回、关注与自选同步、收藏、语言切换时保留原文，以及历史的选择、删除、撤销和刷新持久化。分别检查宽屏、窄屏和深色主题。

## 文件分工

- `src/App.tsx`：页面、导航和交互状态。
- `src/data.ts`：资讯、资产、主题、作者和场景说明。
- `src/market-overview.ts`：市场概览候选项、默认值和选择排序逻辑。
- `src/demo-records.ts`：默认个人记录及按标识补充示例的逻辑。
- `src/store.ts`：浏览器本地存储。
- `src/i18n.ts`、`src/translations.json`：显示文本翻译和双语搜索；业务标识不随语言变化。
- `src/style.css`：响应式布局与主题。
- `tests/`：翻译、搜索和示例数据测试。

## 发布

网站通过 ChatGPT Sites 公开托管。`.openai/hosting.json` 保存现有 Site 的标识和静态目录配置，后续更新复用该 Site。

发布应用修改时，检查并构建源码，保存对应版本，再发布静态产物。不要上传本地浏览器记录或凭据。显示名称与网址前缀是独立设置，当前均为 `sift-demo`。
