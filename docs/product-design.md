# 产品设计

Sift 帮助读者发现重要变化、理解它与自己的关系、核对依据，并继续追问。主要路径是：**选择关心的内容 → 阅读简报 → 查看依据 → 带着上下文提问**。

本文说明产品目标与取舍。[内容规则](content-rules.md)定义信息如何组织，[演示说明](demo.md)说明当前真正实现了什么。

## 设计原则

简单清晰意味着减少需要理解的概念和隐藏的交互规则，同时保留信息含义与依据。一个小按钮背后也可能需要一整套采集、推断、通知和维护系统，因此应按完整责任判断功能成本。

1. **每个入口承担明确任务。** 简报提供可以读完的一期内容，探索承接持续更新。新增入口需要解决现有入口无法清楚解决的问题。
2. **复用规则，保留必要边界。** 事件和专题共享引用与版本规则；来源内容、综合整理和简报各自保留身份与更新时间。
3. **选择明确，能够修改。** 关注、自选、兴趣和临时筛选相互独立。阅读和提问不会悄悄改变长期偏好。
4. **按需展开信息。** 优先呈现正文和阅读理由，引用、历史等辅助信息按需展开。已确认的重要错误仍需直接提示。
5. **先验证，再扩展。** 从有限的内容目录和可复用的公共整理开始。只有反复出现的需求和可承担的运营责任，才足以支持更复杂的功能。

## 核心概念

**内容**是面向读者的阅读对象，类型说明其性质：报道、观点、行情观察、事件、专题或简报。按形成方式，前三类属于来源内容，事件与专题属于综合整理，简报按期组织重点。这个划分用于说明规则，无需再增加一组界面标签，也不要求所有类型拥有相同字段、页面或存储结构。

| 概念 | 含义与边界 |
| --- | --- |
| 来源 | 可关注的发布主体，可以是媒体、机构、作者或固定的“作者·媒体”组合。受访者或被引用者只在正文署名。 |
| 发布记录 | 一个来源某次发布或修订的不可变记录，保留正文、来源、发布时间和接收时间，是引用与追溯的基础。 |
| 来源内容 | 一项来源作品，可关联确认相同或实质等同的其他发布，以及该作品的修订。展示时选择一条合格记录，正文、来源和时间始终对应。 |
| 综合整理 | 有独立文案、依据和版本的整理。“事件”围绕具体事情，“专题”回答明确问题。 |
| 简报 | 截至某个时间的一期内容，固定保存重点摘要、顺序和引用。 |
| 主题 | 表示讨论范围，服务兴趣、搜索和筛选，允许重叠，无独立详情或订阅。 |
| 资产与市场 | NVDA、BTC 等是具体资产，市场组织行情浏览。同市场或同主题不自动产生内容与资产关系。 |

每条发布记录只有一个来源，一项来源内容可以包含多个来源的等同发布。折叠重复只减少曝光，不混写正文；高度相似仍需核对关键事实、限定条件与观点。修订保留新旧记录，独立更正声明和不同说法保留为独立内容，再关联到对应记录。更正无需成为新类型。

例如，A 的园区报道被 B 原样转载，两条记录可以折叠。A 后来更正交付月份，新记录连接 A 的旧版，B 仍保留旧文。另一份讨论电网接入进度的报道继续独立，两份报道可以共同支撑事件、专题或简报。

内容复用收藏、历史与追问等能力，引用始终定位具体版本。事件和专题直接引用来源记录，彼此的延伸阅读只负责导航；简报可以引用来源内容或综合整理，无需为每个重点先创建事件。具体版本和折叠规则见[内容规则](content-rules.md)。

## 四个主要模块

### 简报：完成一次阅读

每日简报按明确截止时间，结合用户选择与信息重要性筛选重点。优先复用公共整理；同一件事的多条进展可以合成一个重点，保留时间顺序和分歧。仅有相同主题的内容不合并。

页面显示日期、截止时间、重点数量、编号、标题、摘要和当前阅读理由，依据按需展开。合成后的重点有自己的表述，不沿用第一份材料的来源、类型和主题来代表整体。

一期发布后，文案、顺序和引用保持固定。刷新和修改偏好不会重写已保存的简报；后续进展进入探索或下一期。实际重复了错误事实的重点可以附上具体说明。阅读理由依据当前偏好显示，与固定的简报正文分开。

支持历史简报、收藏和围绕本期追问。首版不加入个人发布时间、周报月报或推送配置。

### 探索：继续发现与查找

| 栏目 | 内容范围 | 排序提示 |
| --- | --- | --- |
| 关注 | 已关注来源的内容 | 最新优先 |
| 推荐 | 与明确选择相关的信息，以及符合条件的重要信息和视野拓展内容 | 相关优先 |
| 热点 | 当前内容目录中的重要报道、行情观察和事件，使用公共排序 | 重要优先 |
| 专题 | 少量持续维护的解释性内容 | 最新优先 |

主题筛选只影响当前浏览，不修改兴趣。内容可以有多个主题，也可以没有；匹配多个兴趣不会重复叠加主题权重。列表默认不重复显示主题，详情与筛选中仍可查看，不另建主题详情页。

在发现内容的场景中，事件可以替代已经纳入的主要报道，减少重复。尚未纳入的新进展仍需显示。关注页保留来源内容，搜索和资产查找允许同时找到原始报道与综合整理。

搜索顺序为“内容、来源、资产”，从特定入口进入时可以默认对应类型。主题名称可以用于搜索，但不增加主题搜索页。搜索范围限于平台目录，空结果不代表外部没有相关信息。

### 行情：提供阅读背景

市场概览保持紧凑，默认展示标普 500、美债 10 年期收益率和美元指数，主要提供美元资产视角。它不代表完整的全球市场概览。用户可选择并排列一至三项，配置只影响展示。

当前资产范围覆盖美股、加密资产和商品。语言选择不改变市场覆盖；扩展市场需要统一考虑全球覆盖目标与数据条件。

行情与“我的”复用一份自选列表。加入自选不表示持仓，不触发交易、通知或主题兴趣。资产详情提供行情、图表、明确关联的内容和追问入口，暂不增加资产标签、资产主题或范围筛选。

相关内容依据正文中明确的资产关系展示，允许主要讨论、比较和背景引用。“自选热点”要求资产是主要讨论对象，不用泛宏观信息补足数量。相关关系也不等于价格变化的因果解释。

行情保留单位、统计区间、状态和时间。收益率变化使用基点，价格涨跌明确比较区间；详细口径与时间按需展开。

### 我的：集中管理个人选择与记录

顺序为“关注与偏好 → 阅读与对话 → 设置”。数量跟随对应入口显示，不单独建设个人数据看板。

- 关注来源与自选资产分别管理，并与其他页面同步。
- 内容偏好支持主题和自然语言描述，保存时展示能够识别的结果，不把无法理解的限定条件扩展成更宽的规则。
- 收藏保存具体版本或整期简报。在收藏、关注、自选列表中取消后，当前访问期间保留该行，允许原地恢复；再次进入时再移除。
- 浏览历史与对话记录分开管理，支持批量操作和页面内撤销。删除历史不影响收藏或关注。
- 通用 AI 入口放在“我的”页；对话历史页不再重复提供新建入口。

首次使用先选择感兴趣的主题，再选择紧凑展示的自选资产。两个步骤都可跳过，跳过不清空已有选择。

## 个性化与阅读理由

关注回答“想看谁发布的”，自选回答“关心哪些资产”，兴趣回答“想了解什么”。它们共同参与推荐和后续简报筛选，彼此不会自动转换为订阅关系。

“多推荐、少推荐、不推荐”有不同作用，明确排除优先。调整推荐不改变公共热点、自选热点、关注页或主动搜索，也不重写已有简报。恢复推荐只撤销相应的负向选择。

推荐与简报显示一条当前阅读理由，优先顺序为自选资产、感兴趣的主题、关注来源。综合整理的来源关系只看主要依据，不把偶然引用的背景材料当成强关联。这条说明帮助理解当前关系，不承担完整排序解释。

没有直接个人关联时，高重要性内容可显示“重要信息”，其他适合拓展阅读的内容可显示“拓展视野”。这些提示不表示事实已获确认、构成交易建议或用户从未了解过。仍须遵守筛选与排除规则；命中“少推荐”的内容不显示正向理由。演示中的具体排序位置见[演示说明](demo.md)。

## 一致的阅读与操作方式

视觉使用白底黑字、蓝色主色调，结合刊物式标题与正文排版。信息与控件使用清晰的无衬线字体；深色模式保持相同层级。优先用字号、间距和分隔线组织页面，减少重复卡片和徽标。

普通内容列表统一为“类型与更新状态 → 标题 → 摘要 → 可选阅读理由 → 来源与时间”，操作按钮放在右侧。主题默认从列表元信息中省略，避免在推荐、搜索、收藏和引用列表中反复堆叠标签；详情保留主题，推荐理由可点明真正相关的兴趣。元信息使用普通文本，来源不带隐藏链接。紧凑的依据列表可以省略摘要，但顶部、底部元信息行应完整显示或整体省略。“综合整理”与其他来源文字保持同一层级，同时不提供来源关注操作。简报重点保留独立结构。

详情先呈现身份、时间、摘要和正文，再呈现辅助部分。引用材料、其他发布、历史版本、相关资产、延伸阅读和文字说明使用一致的折叠行，默认收起；重要错误说明保持可见。引用打开指定版本，延伸阅读打开最新版本；返回时保留滚动与展开状态。

外链名称对应真实目的地：原文、参考资料或来源网站不能混称。当前示例链接到支撑材料时使用“查看参考原文”，虚构报道不编造原文地址。

图片和视频融入正文，提供说明、署名与替代文本，媒体由用户主动播放。缩略图服务于阅读，不另设媒体频道。语言切换保留同一来源身份，不自动换成另一篇本地语言报道。

AI 入口统一使用星光图标。详情按钮保留动作文字，页面顶部可用带无障碍名称的单独图标。会话内的新建操作沿用初始内容版本、简报或资产上下文，不复制消息；首次提问后才保存会话，已有回答不随材料更新而重写。

左右滑动只切换探索、行情内部的标签。简报、探索、行情支持下拉刷新，不另设显式刷新按钮，也不借刷新重新生成已有简报。时间跟随设备时区，个人偏好原文和对话原文不随界面语言改变。

## 范围与扩展条件

目标首版需要有限且获得授权的内容目录、可靠的行情与版本信息、少量公共事件和专题、每日简报，以及有依据的上下文问答。演示尚未实现这些后端服务。

暂不加入外部账户接入、自定义来源、行为推断、长期记忆、资产标签、嵌套内容集、异常行情扫描、推送、观点评分、社交与成长系统。

当专业覆盖缺口反复阻碍阅读时，再考虑扩展来源；当资产查找经常失败时，再评估更细筛选；当用户经常回顾自己的判断时，可先验证一条附在收藏上的笔记，再考虑完整复盘。每项扩展都应明确负责人、持续成本、失败处理和验证指标。

主要观察读者能否更快了解变化、解释关键事实、找到依据，以及误合并、发布延迟和编辑成本。页面数量、停留时长和内容产量不能单独证明产品价值。
