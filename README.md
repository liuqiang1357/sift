# Sift

围绕关注与偏好的财经资讯助手，包含简报、探索、行情和我的四个模块。

[在线 Demo](https://sift-demo.liuqiang1357.chatgpt.site) · 资讯、行情和 AI 回答均为演示数据。

## 本地运行

需要 Node.js 22.12 或更高版本。

```sh
npm ci
npm run dev
```

打开 [本地 Demo](http://127.0.0.1:5173/)。技术栈为 React 19、TypeScript 7、Vite 8。
